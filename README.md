## 🚀 Featured Projects

### 1. Human Behaviour Analysis Using EEG Brain Signals

An ML-based application that analyses EEG-derived feature data to classify human behavioural states.

- Multiple classification algorithms: Random Forest, SVM, Logistic Regression, KNN and Decision Tree.
- CSV-based data upload and prediction.
- Visualisation of predicted behaviour categories.
- AI-generated interpretations using a locally running Ollama language model.
- Built with Python, Flask and Machine Learning.

**Repository:** [Human Behaviour Analysis](https://github.com/jatin-cse/Human-Behaviour-Analysis-Final-Version)

### 2. Hand Gesture Recognition

Computer vision projects exploring real-time hand tracking and gesture-based interactions.

- Hand gesture recognition.
- Camera-based hand tracking.
- Gesture-driven interaction experiments.

**Technologies:** Python, OpenCV, MediaPipe.

### 3. Cognitive Trace Recorder

A developer-tool project exploring the recording of programming-related cognitive context during development.

**Technologies:** JavaScript, VS Code Extension API.
