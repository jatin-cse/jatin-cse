## 🚀 Featured Projects

### 🧠 Machine Learning & Computer Vision

#### 1. Human Behaviour Analysis Using EEG Brain Signals

An EEG-based machine learning application designed to classify behavioural states using EEG-derived features.

- Multiple ML classifiers: Random Forest, SVM, Logistic Regression, KNN and Decision Tree.
- CSV-based feature upload and prediction.
- Behaviour category distribution visualisation.
- AI-generated interpretation using a locally running Ollama model.
- CSV export functionality.

**Technologies:** Python · Flask · Scikit-learn · Pandas · NumPy · Ollama

🔗 [View Repository](https://github.com/jatin-cse/Human-Behaviour-Analysis-Final-Version)

#### 2. Hand Gesture Recognition

Computer vision projects focused on real-time hand tracking and gesture-based interaction.

- Real-time hand tracking.
- Gesture recognition experiments.
- Gesture-based interaction applications.

**Technologies:** Python · OpenCV · MediaPipe

🔗 [View Repository](https://github.com/jatin-cse/hand-gesture)
